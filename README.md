# CloudConnect Communications Demo

A standalone React/Vite technical demonstration of a unified communications platform.

## Included
- Communications overview dashboard
- SMS inbox concept
- Voice call interface
- AI workflow orchestration
- CRM / PMS / EHR integration patterns
- REST API and webhook concepts
- Reliability and latency monitoring
- Responsive mobile layout

## Run locally
npm install
npm run dev

## Deploy
This repository is Vercel-ready. Import the repository into Vercel and use the default Vite build settings.

## Disclaimer
This is an independent technical demonstration created for portfolio/proof-of-capability purposes. It is not Mango Voice's actual product and is not affiliated with Mango Voice or any communications provider.
